    Handcrafted features

    What a physics feature actually sees

    Every window of ankle acceleration is split by a 0.3 Hz low-pass filter into the gravity component and the body motion left behind, then differentiated into jerk. These are real windows from the dataset — pick an activity and watch the decomposition redraw.

    Standing to running, the same five numbers move by orders of magnitude. Jerk energy climbs from 158 to 849,034; body-acceleration energy from 0.03 to 333. Gravity magnitude barely moves for a still subject and scatters wildly for a running one — that spread is exactly what the classifier keys on.

    Results

    Which features actually win

    Thirty-six configurations, each scored by leave-one-subject-out: ten folds, every fold tested on a person the model never trained on. Sort by any metric, or filter to one classifier.

    statistical physics mixed / combined

    Statistics beat physics alone; together they beat both. Statistical features carry more raw discriminative power (0.961 vs 0.941 macro F1 with a random forest), but the top-40 mixed set wins every metric — and does it with a fifth of the features. Random forests dominate SVM and MLP at every feature count.

    Read the top-k rows with care. Their feature ranking was computed once across all ten subjects, which flatters them by roughly a point and a half. The three full-family rows — statistical, physics, and both — involve no selection at all and are the honest comparison.

    Evaluation protocol

    Why the random split had to be thrown out

    Five-second windows cut from one continuous minute of recording are near-duplicates. Split them at random and train and test share the same moments — every feature family scores a perfect 1.000 and the comparison tells you nothing.

    The CNN drops 0.113 macro F1 when it meets a new person; the handcrafted features lose almost nothing. With 1,335 windows from ten people, the network partly learns who is moving rather than how they move. Handcrafted features do not have that option.

    Feature invariance

    Which features survive a new body

    Each dot is one feature, placed by how far its within-activity average drifts between subjects relative to its overall spread. Left is invariant; right changes with whoever is wearing the sensor. Hover any dot.

    physics · mean 0.754 statistical · mean 0.876

    The six most subject-invariant features in the whole set are all physics ones — gravity-magnitude spread and tilt-angle spread at the ankle, wrist and chest. They describe how the sensor sits and swings against gravity, which is a property of the movement, not of the mover.

    Validity checks

    Is any of this leaking?

    Five activities scoring a perfect 1.000 is the kind of result that should be doubted before it is published. Four checks, all reproducible by check_leakage.py.

    Feature ranking computed on all subjects0.9780.964inflated by 1.4 pts

    The split is clean; the feature selection was not. If test-subject information reached training, a model fed scrambled labels would still beat chance — it does not, in either permutation. But ranking the top 40 features once across all ten subjects let the selection glimpse each held-out person, and that alone was worth 1.4 points. Every number on this page now comes from a ranking recomputed inside each fold.

    What the perfect classes really rest on. Each activity contributes about 111 windows, but they come from only ten people — roughly eleven consecutive windows cut from one continuous minute per subject. Ten independent observations per class, not 111. A perfect 1.000 on lying means ten people’s lying blocks were all classified correctly, which is a much smaller claim than the window count suggests.
